# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

static HTML/CSS/JS in `web/`. Delegated: smallest stack that can look like a real board. Bend stays for laws and proofs only.

## Users

Engineers planning a repo on a desktop monitor in office daylight. They place schema, API, and effect cards, then edit the real vendor text.

## Product Purpose

data-based is an invite-only diagramming board for software shape. Success is placing a named element and editing it in that vendor’s language without leaving the board.

## Positioning

Assumed from the brief: the board is the product. Cards are typed (SQL, Prisma, Drizzle, GraphQL, effects), not generic sticky notes. Neighboring whiteboards cannot truthfully claim vendor-native round-trip editors.

## Operating Context

Browser at `web/index.html`. Marketplace of vendor elements. Double-click or Edit opens a modal. Invite-only stub. No public signup. Native `App.run` is not the UI.

## Capabilities and Constraints

- Place, select, move, resize, and edit cards
- Double-click opens edit; a drag must not
- Prisma / Drizzle / GraphQL / SQL raw panes are that language, bidirectional with fields
- Effect cards edit input type, output type, and in-box effects
- Assumed: no live presence, no AI chat, no auth product in this pass
- Bend `PROOF.bend` stays green if laws are touched

## Brand Commitments

Name is **data-based**. User rejected unlabeled native squares and the first web chrome (dark rail + cream grid). Craft bar named by the user: FigJam, Whimsical, Linear. No Clerk/Next.js unless needed. No public signup.

## Evidence on Hand

No customers, screenshots of a liked design, or brand assets. Do not invent testimonials.

## Product Principles

- The canvas is the work; chrome floats and recedes
- Every element speaks its vendor’s language
- Text, spacing, and contrast first. Color chips are not a UI
- Invite-only. Do not pretend there is a public product
- Assumed facts in this file are labeled assumed

## Accessibility & Inclusion

Keyboard: H marketplace, E edit, V select, Space pan, Esc close, Delete remove. Focus rings required. Body text ≥ 4.5:1.
